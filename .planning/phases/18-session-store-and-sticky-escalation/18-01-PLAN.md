<resolved_decisions>

**1. SessionState lives in Core (Domain.fs), ISessionStore in Cli (18-02).**

Per 17-RESEARCH and 18-RESEARCH (Anti-Pattern 3): the `SessionState` record is a BCL-only data shape — `ModelId` + `DateTimeOffset` + `int64`. It belongs in `SmartRouter.Core/Domain.fs` because the algorithm closure (constructed in CompositionRoot in 18-02) will need to inspect `LastModel` and return a `RoutingDecision`. Keeping `SessionState` in Core keeps the Phase 19 `makeSelfRoutingAlgorithm` closure pure-typed.

The `ISessionStore` *interface* and the `SessionStore` *class* (which carry Serilog/IHostedService/ConcurrentDictionary references) live in `SmartRouter.Cli.Adapters.SessionStore` — added in Plan 18-02. ARCH-01 preserved.

**2. `mutable LastAccessSeq` on the SessionState record.**

Phase 16's `JudgeClient.CacheEntry` uses the identical pattern (mutable `AccessSeq : int64` on a private record). The mutable field is in-place updated on every read via `Interlocked.Increment` to maintain LRU ordering without dictionary key churn. Pure data field on a Core record is acceptable under ARCH-01 — mutation happens in the Cli adapter (18-02 SessionStore), not in Core.

**3. 8-arm exhaustive match enforced at compile time.**

`TreatWarningsAsErrors=true` is project-wide. Adding `StickyEscalation` to the DU without adding the `formatReason` arm produces FS0025 (incomplete pattern match) → build fails. This is the design — the compiler catches missing arms. Phase 17 added `HardRule` the same way; the pattern is proven.

**4. ChatCompletions.fs Production construction sites.**

Two sites. Both updated in Task 3 to carry `SessionId = ""`. The `sessionId` *parameter* threading on `mapWireToRequest` (signature change adding a 2nd string parameter; reading from `ctx.Items[SessionIdKey]`) is deferred to Plan 18-02 — that work requires `CorrelationMiddleware` to be extended first (also 18-02). Plan 18-01 satisfies the compile dependency by hardcoding `SessionId = ""` in both production records; 18-02 then replaces the hardcoded empty string with the real header-derived value.

**5. No SessionState equality/comparison required.**

The record contains `ModelId` (a DU) + `DateTimeOffset` + `int64`. Default F# structural equality applies. If 18-02 needs reference equality semantics on the dictionary entries, the dictionary key/value pattern (ConcurrentDictionary<string, SessionState>) handles it via key-based ops — no [<NoEquality>] or [<NoComparison>] attribute needed on SessionState.

</resolved_decisions>
