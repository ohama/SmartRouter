**Sub-change A — Named `"selfrouter"` HttpClient registration** (RESEARCH §1, "JudgeClient HttpClient registration in CompositionRoot" + RESEARCH "Code Examples — Named HttpClient Registration"):

Inside the `"selfrouting"` arm of the `RoutingAlgorithmRegistration` factory mode-switch (the same `| _ ->` branch where the Phase 18 sticky closure lives — see CompositionRoot.fs lines 500-527 around `Name = "selfrouting"`), BEFORE the `RoutingAlgorithmRegistration` factory itself but inside the same mode-gated block, register:

```fsharp
// Phase 19 (SR-01): named "selfrouter" HttpClient — 5s timeout (NOT 300s),
// 1 retry at 200ms. Separate from "upstream35b" (300s inference timeout) to
// prevent classify calls from inheriting inference resilience config.
// Mode-gated: only registered when Routing.Mode="selfrouting".
// Mirrors the "judge" registration shape at CompositionRoot lines ~668-689.
let selfRouterOpts =
    let raw = config.GetSection("Routing:SelfRouter").Get<SelfRouterOptions>()
    let effective : SelfRouterOptions = {
        Endpoint        = if isNull (box raw) || String.IsNullOrWhiteSpace(raw.Endpoint) then upstreamOptsLazy.Model35B else raw.Endpoint
        PromptPath      = if isNull (box raw) || String.IsNullOrWhiteSpace(raw.PromptPath) then "prompts/self-router-prompt.md" else raw.PromptPath
        TimeoutSeconds  = if isNull (box raw) || raw.TimeoutSeconds  <= 0 then 5     else raw.TimeoutSeconds
        MaxCacheEntries = if isNull (box raw) || raw.MaxCacheEntries <= 0 then 10000 else raw.MaxCacheEntries
    }
    effective

services.AddHttpClient("selfrouter", fun (c: System.Net.Http.HttpClient) ->
    c.BaseAddress <- Uri(selfRouterOpts.Endpoint)
    c.Timeout     <- TimeSpan.FromSeconds(float selfRouterOpts.TimeoutSeconds))
    .AddResilienceHandler("selfrouter-pipeline", fun (builder: Polly.ResiliencePipelineBuilder<System.Net.Http.HttpResponseMessage>) ->
        let retryOpts = Microsoft.Extensions.Http.Resilience.HttpRetryStrategyOptions()
        retryOpts.MaxRetryAttempts <- 1   // SR-01: 1 retry (judge uses 2; selfrouter is more aggressive — fail fast to fail-open default)
        retryOpts.BackoffType      <- Polly.DelayBackoffType.Constant
        retryOpts.Delay            <- TimeSpan.FromMilliseconds(200.0)
        builder.AddRetry(retryOpts) |> ignore
        builder.AddTimeout(TimeSpan.FromSeconds(float selfRouterOpts.TimeoutSeconds)) |> ignore)
    |> ignore
```

**WARNING (RESEARCH §1):** Use the `AddHttpClient(name, fun c -> ...).AddResilienceHandler(...)` form OR the `AddHttpClient(name).ConfigureHttpClient(...)` form — whichever matches the established judge registration form in the same file (CompositionRoot lines 668-689). Do NOT use the 2-arg `AddHttpClient(name, configure)` lambda form alone — it silently drops BaseAddress in F#. Match `judge`'s working form exactly.
