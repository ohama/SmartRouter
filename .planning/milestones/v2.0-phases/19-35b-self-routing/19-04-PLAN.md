**Sub-change A — §5.7 (NEW) Stage 4 Self-Classify**

Add a new sub-section within § 5 Routing Pipeline. Suggested content (adapt phrasing to match the existing README voice):

```markdown
### 5.7 Stage 4 — 35B Self-Classify (v2.0)

For **non-streaming** requests that reach the routing default stage without being decided by Hard Rules (Stage 0), an explicit model or task override (Stage 1/2), or a sticky session (Stage 3), the router calls the 35B model itself to classify the prompt as SAFE (handle on 35B) or UNSAFE (escalate to 122B).

**Mechanics:**
- The router sends a small classify request via the named `"selfrouter"` HttpClient (separate from `"upstream35b"` — 5s timeout, 1 retry at 200ms, not the 300s inference timeout).
- Request body: `max_tokens=8`, `temperature=0`, `stream=false`, single user message built from `prompts/self-router-prompt.md` with the user's prompt substituted into the `{{PROMPT}}` placeholder.
- The 1-word response is parsed safety-biased: if both "SAFE" and "UNSAFE" appear (or output is ambiguous), the verdict is **UNSAFE** (escalate to 122B). This protects against the substring collision (`SAFE` ⊂ `UNSAFE`).
- The result is stamped in the DecisionLog with `routing_reason="self_route"`, `routing_algorithm="selfrouting"`, and `model_version="selfrouting-{hex8}"` (first 8 hex chars of SHA-256 of `prompts/self-router-prompt.md`).
- Repeated prompts hit a per-process LRU cache keyed by SHA-256 of the full conversation content (`prompt_hash`); cache hits skip the HTTP round-trip entirely. Bounded at 10,000 entries by default.
- Failure modes (template missing, HTTP timeout, garbage response, model returns neither word) **fail open** to the existing Stage 5 default (Qwen 35B). No request is dropped; the operator sees `selfrouter_skipped` or `selfrouter_call_count` movements in `/stats`.

**Streaming requests skip Stage 4 entirely.** The latency budget for the first SSE chunk (~100ms p50) cannot absorb a classify round-trip (5s timeout + 35B inference ~200-500ms). Hard Rules (Stage 0) and sticky escalation (Stage 3) still apply to streaming via `routeRequest`.

**Operator tuning:** Edit `prompts/self-router-prompt.md` to refine SAFE/UNSAFE classification criteria. Changes take effect on next router restart (the template is read on first request after boot and cached for the process lifetime; `model_version` in DecisionLog will change after restart, signaling the new template is active).

**Operator override:** Set `Routing.Mode="ml"` in `appsettings.json` to disable Stage 4 entirely and route through the v1.x ML classifier (Phases 6-9, 14-16 code path). See § 7.
```

**Update the §5 cascade summary diagram** (likely at the top of § 5.5 or wherever the cascade is enumerated) to reflect the full v2.0 stage list:

```
Stage 0: Hard Rules keyword scan (all requests including streaming)
Stage 1: Explicit model override (model=35b/122b in request body)
Stage 2: Explicit task table (task=compiler_debug etc.)
Stage 3: Sticky session escalation (X-Session-Id header)
Stage 4: 35B self-classify — SAFE → 35B / UNSAFE → 122B (NON-STREAMING ONLY) ← v2.0
Stage 5: Default 35B
```

```markdown
#### `Routing.SelfRouter` (v2.0)

Active only when `Routing.Mode="selfrouting"` (the v2.0 default). Ignored when `Routing.Mode="ml"`.

| Key | Default | Purpose |
|-----|---------|---------|
| `Routing.SelfRouter.Endpoint` | `""` (empty → derive from `Upstreams.Model35B`) | Override URL for classify calls. Almost never set — Stage 4 is by design same-model as inference (§ 5.7). |
| `Routing.SelfRouter.PromptPath` | `"prompts/self-router-prompt.md"` | Path to the operator-tunable classify prompt template. Must contain `{{PROMPT}}` placeholder. |
| `Routing.SelfRouter.TimeoutSeconds` | `5` | HTTP timeout for the classify call. Raising masks slow-35B-server symptoms; 5s is a tight latency budget. |
| `Routing.SelfRouter.MaxCacheEntries` | `10000` | LRU bound on the per-process prompt-hash → verdict cache. Lower values cause more HTTP traffic; higher values use more memory. |

**Operator note:** Changing `PromptPath` or editing the file at that path requires a router restart to take effect (template is read on first request and cached). The DecisionLog `model_version` field will change to a new `selfrouting-{hex8}` value after restart, confirming the new template is active.
```
