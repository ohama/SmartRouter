<objective>
Ship the BCL-only `ContentFingerprint` adapter — a pure, synchronous Cli adapter that computes a deterministic 16-character lowercase hex prefix of `SHA-256(truncate(system) + "|||" + truncate(firstUser))` from a `RouterRequest`, where `truncate(s) = if s.Length > 4000 then s.[..3999] else s`. Covers REQUIREMENTS CFP-01, CFP-02, CFP-03, CFP-04 (6 test cases: determinism, uniqueness, truncation, empty-message, Korean+English UTF-8, 16-char lowercase output).

Purpose: This is the Tier 3 fallback for the v2.1 cascade in Phase 22 — used when neither `X-Session-Id` header (Tier 1) nor Hermes' `Session ID:` system-prompt line (Tier 2, from Plan 21-01) is present. By hashing the conversation prefix, it gives the same session key across multi-turn continuations of the same conversation, enabling sticky-122B continuity for clients that don't propagate Hermes session ids and don't send explicit headers. Plan 21-01 must land first (Wave 1) because the Cli.fsproj Compile order places `ContentFingerprint.fs` directly after `HermesSessionExtract.fs`.

<resolved_decisions>

**1. File placement: `SmartRouter.Cli.Adapters` not `SmartRouter.Core`** (locked)

Same rationale as Plan 21-01. ROADMAP.md §Architectural Invariants ARCH-01: "Both new files (`HermesSessionExtract.fs`, `ContentFingerprint.fs`) live in `SmartRouter.Cli.Adapters` — NOT in `SmartRouter.Core`." Module declaration: `module SmartRouter.Cli.Adapters.ContentFingerprint`.

**2. Per-call `use sha = SHA256.Create()`, NOT module-level instance** (locked by 21-RESEARCH.md Pitfall 2)

`SHA256.Create()` returns a stateful, NOT-thread-safe instance. A module-level `let private sha = SHA256.Create()` would cause concurrent requests to corrupt each other's hash state, producing wrong hashes silently. The established project pattern is per-call `use sha = SHA256.Create()` (see `CorrelationMiddleware.fs:69-72` and `SelfRouter.fs:168-172`). The `use` binding disposes correctly within the function scope.

**3. Lowercase hex via `Array.map (sprintf "%02x") |> String.concat ""` — NOT `Convert.ToHexString`** (locked by Phase 20 pitfall)

`Convert.ToHexString(bytes)` returns UPPERCASE hex. The project convention (documented in `HermesFingerprintTests.fs` FP-3 comment, line 76: "do not use Convert.ToHexString") is the `sprintf "%02x"` pattern, used in `CorrelationMiddleware.fs:72` and `SelfRouter.fs:171`. CFP-04 case (f) tests that all output chars are in `[0-9a-f]` — `Convert.ToHexString` would fail this. Researcher 21-RESEARCH.md §Alternatives Considered.

**4. Truncation: `s.[..3999]` is INCLUSIVE on both ends in F#** (locked by spec)

CFP-01 spec text: `truncate(s) = if s.Length > 4000 then s.[..3999] else s`. In F#, `s.[..3999]` produces characters at indices 0 through 3999 inclusive — exactly 4000 characters. The condition `s.Length > 4000` means a string of exactly 4000 characters is NOT truncated (passes through unchanged). 21-RESEARCH.md Pitfall 3.

**5. Empty-message edge case: hash of `"|||"` returns a valid 16-hex string — DO NOT special-case** (locked by CFP-02)

CFP-02: "the function always returns a valid 16-hex string (no `option` wrapper)". When both `system` and `firstUser` are absent, `key = "" + "|||" + "" = "|||"`. SHA-256("|||") is a stable, deterministic value. **Anti-pattern**: an `if key = "|||" then "0000000000000000"` short-circuit defeats determinism and contradicts CFP-02. Just let SHA-256 run on the separator. 21-RESEARCH.md Pitfall 4.

**6. Test case (d) — assert determinism + format, NOT a hardcoded magic constant** (locked by researcher recommendation)

21-RESEARCH.md §Open Questions item 2 + §Test Design: for the empty-message case, the test should call `compute` twice and assert equality + assert length=16 + assert lowercase-hex format. **Do NOT** hardcode the precomputed SHA-256("|||") hex prefix (e.g., `"8ca4d4e3c19a1c14"`) — this couples the test to a magic constant that obscures intent and would silently rot if the truncate or separator changed accidentally. The format+determinism assertions catch all the same regressions without the magic value.

**7. Truncation HAPPENS on character boundary, encoding HAPPENS after truncation** (locked by spec)

`s.Length` in .NET is char count (UTF-16 code units), not byte count. The spec truncates on the character boundary; UTF-8 encoding (`Encoding.UTF8.GetBytes(key)`) happens AFTER truncation. This is correct. Do NOT try to truncate by byte count. 21-RESEARCH.md Pitfall 3 + Anti-Patterns.

**8. Insertion point in `SmartRouter.Cli.fsproj`** (locked by 21-RESEARCH.md)

Place `<Compile Include="Adapters/ContentFingerprint.fs" />` immediately after `<Compile Include="Adapters/HermesSessionExtract.fs" />` (added by Plan 21-01). Both new files form a contiguous Phase-21 block, sandwiched between `SessionStore.fs` and `DecisionLogger.fs`. No within-project compile-order dependency between the two new files (neither references the other) — they could be in either order, but keeping them adjacent and in plan-number order is the established convention.

**9. `MessageRole.User` pattern match is case-checked but unambiguous** (locked by Domain.fs precedent)

`Message.Role = User` syntax works because the `MessageRole` DU is unambiguous when `SmartRouter.Core.Domain` is opened. Same pattern as `m.Role = System` in Plan 21-01 and `m.Role = User` in `HardRulesTests.fs:12`. F# does not require `MessageRole.User` qualification.

**10. No `testSequenced` wrapper** (locked by precedent)

Same as Plan 21-01. `ContentFingerprintTests` is pure: no Console.SetOut, no temp dirs, no DefaultHttpContext. `HardRulesTests.fs` is the precedent. Confirmed in 21-RESEARCH.md §Open Questions item 3.

    ```fsharp
    module SmartRouter.Cli.Adapters.ContentFingerprint

    open System.Security.Cryptography
    open System.Text
    open SmartRouter.Core.Domain

    // ── Truncate helper (CFP-01) ─────────────────────────────────────────────
    //
    // Spec-exact: REQUIREMENTS.md CFP-01 says
    //   truncate(s) = if s.Length > 4000 then s.[..3999] else s
    //
    // F# slice `s.[..3999]` is INCLUSIVE on both ends — indices 0..3999 yield
    // exactly 4000 characters. A 4000-char string passes through unchanged
    // (the condition is strict `> 4000`). A 4001-char string is truncated to
    // 4000 chars. .NET `String.Length` is char count (UTF-16 code units), not
    // byte count — truncation happens on the character boundary BEFORE UTF-8
    // encoding (21-RESEARCH.md Pitfall 3).
    let private truncate (s: string) : string =
        if s.Length > 4000 then s.[..3999] else s

    // ── compute (CFP-01 / CFP-02 / CFP-03) ───────────────────────────────────
    //
    // Returns a 16-character lowercase hex prefix of the SHA-256 digest of
    //   key = truncate(system) + "|||" + truncate(firstUser)
    //
    // Per CFP-02: always returns a valid 16-hex string — no `option` wrapper.
    // When both system and firstUser are absent, key = "|||" and SHA-256 still
    // produces a stable, deterministic value (CFP-04 case d). DO NOT special-case
    // the empty-message branch (21-RESEARCH.md Pitfall 4).
    //
    // SHA256 lifecycle (21-RESEARCH.md Pitfall 2):
    //   - `use sha = SHA256.Create()` — per-call instance, disposed at scope exit.
    //   - SHA256 is NOT thread-safe; a module-level shared instance would corrupt
    //     concurrent hash computations silently. Matches the project pattern in
    //     CorrelationMiddleware.fs:69 and SelfRouter.fs:168.
    //
    // Hex encoding (21-RESEARCH.md §Alternatives Considered + Phase 20 pitfall):
    //   - `Array.map (sprintf "%02x") |> String.concat ""` produces LOWERCASE.
    //   - DO NOT use `Convert.ToHexString` — it produces UPPERCASE, which fails
    //     CFP-04 case (f). Matches the project pattern in CorrelationMiddleware.fs:72
    //     and SelfRouter.fs:171.
    /// Compute a 16-character lowercase hex content fingerprint for the request's
    /// conversation prefix. Pure: no I/O, no DI, no mutation of req. Deterministic
    /// for any given (system, firstUser) pair. Tier 3 of the v2.1 session cascade.
    let compute (req: RouterRequest) : string =
        let system =
            req.Messages
            |> List.tryFind (fun m -> m.Role = System)
            |> Option.map (fun m -> m.Content)
            |> Option.defaultValue ""
        let firstUser =
            req.Messages
            |> List.tryFind (fun m -> m.Role = User)
            |> Option.map (fun m -> m.Content)
            |> Option.defaultValue ""
        let key = truncate system + "|||" + truncate firstUser
        use sha = SHA256.Create()
        let bytes = sha.ComputeHash(Encoding.UTF8.GetBytes(key))
        let hex = bytes |> Array.map (sprintf "%02x") |> String.concat ""
        hex.Substring(0, 16)
    ```

    module SmartRouter.Tests.ContentFingerprintTests

    open Expecto
    open SmartRouter.Core.Domain
    open SmartRouter.Cli.Adapters.ContentFingerprint

    // ── Test helpers ──────────────────────────────────────────────────────────

    /// Build a RouterRequest with a System message + first User message.
    let private mkReq (systemContent: string) (userContent: string) : RouterRequest =
        { Messages       = [ { Role = System; Content = systemContent }
                             { Role = User;   Content = userContent } ]
          ModelOverride  = None
          Task           = None
          Stream         = false
          Temperature    = None
          TopP           = None
          MaxTokens      = None
          CorrelationId  = ""
          SessionId      = ""
          UnknownFields  = Map.empty }

    /// Build a RouterRequest with no messages at all (Messages = []).
    /// Both system and firstUser resolve to "" — key = "|||".
    let private mkReqEmpty () : RouterRequest =
        { Messages       = []
          ModelOverride  = None
          Task           = None
          Stream         = false
          Temperature    = None
          TopP           = None
          MaxTokens      = None
          CorrelationId  = ""
          SessionId      = ""
          UnknownFields  = Map.empty }

    /// Hex char predicate — true iff c is a lowercase hex digit [0-9a-f].
    let private isLowerHex (c: char) : bool =
        (c >= '0' && c <= '9') || (c >= 'a' && c <= 'f')

    /// Assert: output is exactly 16 chars and every char is lowercase hex.
    let private assertHexFormat (result: string) =
        Expect.equal result.Length 16
            "fingerprint must be exactly 16 characters"
        Expect.isTrue (result |> Seq.forall isLowerHex)
            (sprintf "all chars must be in [0-9a-f]; got %A" result)

    // ── Tests (CFP-04 cases a-f) ─────────────────────────────────────────────

    let tests : Test =
        testList "ContentFingerprintTests" [

            // (a) determinism — same input twice → identical output
            testCase "(a) determinism: identical input produces identical output" <| fun () ->
                let req = mkReq "You are a router." "hello world"
                let r1 = compute req
                let r2 = compute req
                Expect.equal r1 r2 "two calls with same input must produce same fingerprint"
                assertHexFormat r1

            // (b) uniqueness — single-char change → different output
            testCase "(b) uniqueness: single-char change in system produces different output" <| fun () ->
                let r1 = compute (mkReq "You are a router." "same user prompt")
                let r2 = compute (mkReq "You are a router!" "same user prompt")
                Expect.notEqual r1 r2 "single char in system should produce different output"

            testCase "(b) uniqueness: single-char change in firstUser produces different output" <| fun () ->
                let r1 = compute (mkReq "common system" "hello world")
                let r2 = compute (mkReq "common system" "hello worle")
                Expect.notEqual r1 r2 "single char in firstUser should produce different output"

            // (c) truncation — >4000-char input handled without exception, hash uses first 4000 chars
            testCase "(c) truncation: 4001-char system handled without exception; truncation collapses tail diffs" <| fun () ->
                let baseStr = String.replicate 4000 "a"   // exactly 4000 'a' chars
                let req4000 = mkReq baseStr "user"
                let req4001A = mkReq (baseStr + "X") "user"   // 4001 chars; X is truncated away
                let req4001B = mkReq (baseStr + "Y") "user"   // 4001 chars; Y is truncated away
                // Should not throw. All three produce valid 16-hex outputs.
                let r4000  = compute req4000
                let r4001A = compute req4001A
                let r4001B = compute req4001B
                assertHexFormat r4000
                assertHexFormat r4001A
                assertHexFormat r4001B
                // Since both 4001-char inputs truncate to the same 4000-char prefix, their
                // outputs MUST equal each other AND equal the 4000-char baseline.
                Expect.equal r4001A r4001B
                    "4001-char inputs that differ only in the truncated tail must produce the same fingerprint"
                Expect.equal r4001A r4000
                    "truncation must collapse to the same fingerprint as the 4000-char prefix alone"

            // (d) empty-message — Messages = [] → key = "|||" → valid 16-hex
            // Per 21-RESEARCH.md Open Question 2: assert determinism + format,

                Expect.equal r1 r2

            testCase "(e) Korean+English mixed UTF-8 produces valid 16-hex" <| fun () ->

                assertHexFormat r

2. **Pitfall 3 — F# slice inclusivity**: `s.[..3999]` is inclusive on both ends → 4000 chars. The condition `s.Length > 4000` (strict greater than) is correct per spec; a 4000-char string passes through. Case (c) test verifies this with a 4000-char baseline + 4001-char comparisons.

3. **Pitfall 4 — empty-input special-case**: When both `system` and `firstUser` are absent, `key = "|||"`. Do NOT add `if key = "|||" then ...` short-circuit. CFP-02 explicitly requires the function "always returns a valid 16-hex string"; SHA-256("|||") is that string.

4. **Phase 20 hex pitfall**: `Convert.ToHexString` produces UPPERCASE. The `sprintf "%02x"` pattern produces lowercase. Verify step 6 of Task 1: `grep -c "Convert.ToHexString"` returns 0.

7. **`use` lifecycle inside function**: F# `use` binds for the function scope; `Dispose` is called on scope exit (including on exception). The SHA256 instance is correctly disposed even if `ComputeHash` throws (it doesn't, but the lifecycle is sound).
